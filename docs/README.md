# Diagrams

All diagrams used in the guides, as standalone SVG files. They are generated by `scripts/generate_diagrams.py`; edit a diagram's function there and run `python3 scripts/generate_diagrams.py` to regenerate it.

**Location:** `research-agent/docs/images/`. The guides in `docs/` link to them with relative paths (`images/<name>.svg`), and the top-level `README.md` links with `docs/images/<name>.svg`. If you copy the guides somewhere else, copy the `images/` folder with them and keep it next to the `.md` files, otherwise the images won't display.

| File | Shows | Used in |
|---|---|---|
| `architecture-overview.svg` | Big picture: guardrails, LangGraph nodes, Jev, MCP, vector DB, LangSmith | `01-architecture.md`, `README.md` |
| `request-sequence.svg` | One request end to end across User, API, Postgres, Redis, Worker, MCP, OpenAI, Jev | `01-architecture.md` |
| `agent-graph-reference.svg` | Reference LangGraph: Jev decision nodes (teal) and LLM generation nodes (purple) | `01-architecture.md`, `08-jev-decision-model.md` |
| `agent-graph-full.svg` | Full-design graph: clarify, semantic cache, per-section fan-out, reviewer loop | `01-architecture.md` |
| `data-model.svg` | Tables jobs, chunks, eval_results and the lg checkpoint schema | `01-architecture.md` |
| `local-topology.svg` | Docker Compose services and the networks connecting them | `01-architecture.md`, `02-setup-local.md` |
| `aws-trust-zones.svg` | AWS deployment: subnets, data tier, NAT egress, external APIs | `01-architecture.md`, `04-security.md`, `06-cloud-deployment.md` |
